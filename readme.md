## Overview
This is the backend for the FTC Note Scout app (FTCNS), a web application that allows users to create and manage notes about FIRST Tech Challenge teams during events. The backend is built with Node.js and Express, and it uses PostgreSQL for data storage. The API provides endpoints for creating, retrieving, updating, and deleting notes.
